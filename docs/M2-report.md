# รายงาน M2 — เงิน: ใบเบิก อนุมัติ จ่าย ตรวจ

วันที่ 1 ต.ค. 69 · สร้างตาม SPEC §9 M2 · ต่อจาก M1 (ยังรอ deploy ขึ้น Supabase)

## สรุป

ระบบใบเบิกครบทั้งวงจรตามที่ทีมใช้อยู่ใน prototype: **ขอ → อนุมัติ → จ่าย (มีรูปหลักฐาน) → ตรวจ / ถาม-ตอบ**
ระบบเลือกผู้อนุมัติ ผู้จ่าย และบัญชีที่จ่ายให้เองตามยอดเงิน ถ้ากดจ่ายซ้ำพร้อมกันจะสำเร็จแค่ครั้งเดียว
และระบบจะไม่ยอมจ่ายถ้าเงินในบัญชีไม่พอ นอกจากนี้มีหน้าโอนเงินระหว่างบัญชี เจ้าของจ่ายแทน โอนให้เจ้าของ (คำนวณยอดที่โอนได้ให้)
กระทบยอดธนาคาร และ **แจ้งเตือนอาร์ตทุกครั้งที่มีการเปลี่ยนบัญชีระดับ CEO** ตามที่ตกลงไว้

## ทำอะไรไปแล้ว

| ส่วน | รายละเอียด |
|---|---|
| ขอเบิก (เป้อ) | ค่าแรงรายวัน + วัสดุในใบเดียว: เลือกคน → โครงการ → ประเภทงาน → ห้อง · บังคับรูปงาน · ค่าแรงดึงจากทะเบียน (แก้ได้เฉพาะอาร์ต) · ค่าใช้จ่ายส่วนกลางต้องแยกรายการ + ใบเสร็จครบทุกรายการ · ห้ามเขียน "ไม่ระบุรายการ" · แสดงก่อนส่งว่าใครอนุมัติ/ใครจ่าย/จ่ายจากบัญชีไหน |
| เลือกผู้อนุมัติ/ผู้จ่าย | ≤ 3,000 นุ้ยจ่ายจากเงินสำรองได้เลย · 3,001–10,000 กวางอนุมัติ แล้วนุ้ยจ่ายจากเงินสำรอง · > 10,000, เงินเดือน, เติมเงินสำรอง กวางอนุมัติและโอนจากบัญชี3 ในขั้นเดียว (ต้องแนบสลิป) |
| จ่าย | ต้องมีรูปผู้รับเงิน/สลิปอย่างน้อย 1 รูป · บันทึกเงินออก 1 รายการต่อ 1 บรรทัด (จึงรู้โครงการทุกบรรทัด) · เงินไม่พอระบบบอกยอดคงเหลือ · เติมเงินสำรอง = ย้ายเงินจากบัญชี3 เข้าเงินสำรองนุ้ย |
| ไม่อนุมัติ | ต้องใส่เหตุผล · ใบเบิกยังอยู่ให้ดูย้อนหลัง · คนงานในใบที่ไม่อนุมัติกลับมาเบิกวันเดียวกันได้ |
| ตรวจ / ถาม-ตอบ | กวางหรือหน่อยกด "ตรวจผ่าน" หรือ "ส่งคำถาม" ได้ · คนขอเบิกตอบในแท็บรายการของฉัน แล้วใบเบิกกลับมารอตรวจ · บันทึกชื่อคนตรวจ |
| ธง (ไม่บล็อก แต่แจ้งผู้ตรวจ) | ไม่มีรูปหลักฐานจ่าย · ไม่มีรูปงาน · ส่วนกลางไม่แยกรายการ · **ค่าใช้จ่ายอสังหาฯ/ส่วนตัว → หอให้เจ้าของยืม** · งานปรับปรุงไม่ระบุห้อง · (เรื่องลงเวลางาน/GPS เปิดใน M3) |
| เบิกเงินเดือน | แสดงเงินเดือน / เบิกแล้ว / รออนุมัติ / เบิกได้อีก · เบิกเกินคงเหลือไม่ได้ · ค่าตั้งต้น เป้อ 17,000 นุ้ย 10,000 อาร์ตแก้ได้ที่แท็บผู้ใช้งาน |
| ทะเบียนคนงาน | **ย้ายมาจาก M3** เพราะต้องมีคนงานที่ข้อมูลครบก่อนจึงจะเบิกค่าแรงได้ · ชื่อ เบอร์ เลขบัตร (ตรวจสูตร) รูปบัตร · เตือนเบอร์ซ้ำ · คนอื่นเห็นเลขบัตรแบบปิดบางส่วน |
| โอน / เจ้าของ | โอนระหว่างบัญชี · เจ้าของจ่ายค่าไฟแทน (นับเป็นต้นทุนหอ ไม่กระทบเงินในบัญชี) · **โอนให้เจ้าของ** = เงิน 3 บัญชี − เงินประกัน − สำรองซ่อม − รอจ่ายจากบัญชี3 ถ้าเกินจะบอกตัวเลขที่โอนได้ · เจ้าของเติมเงิน (ไม่นับเป็นรายได้) |
| บัญชีระหว่างเจ้าของกับหอ | ยอดยกมา ม.ค.–ก.ย. + ค่าใช้จ่ายอสังหาฯ ใหม่ − ค่าไฟที่เจ้าของจ่ายแทน − เงินที่เจ้าของเติม → "เจ้าของค้างหอ / หอค้างเจ้าของ" |
| ยอดบัญชี | ยอดแต่ละบัญชีคำนวณจากรายการเงินเข้า-ออก (ไม่ได้เก็บตัวเลขไว้ตรงๆ) · กวางใส่ยอดจากแอปธนาคาร ถ้าไม่ตรงจะขึ้นแจ้งเตือน · ดูรายการเงินเข้า-ออกล่าสุดได้ |
| **แจ้งเตือนบัญชี CEO** | ทุกครั้งที่มีการสร้าง ให้สิทธิ์ ถอดสิทธิ์ ปิด หรือเปิดบัญชีระดับ CEO (ไม่ว่าใครเป็นคนทำ) จะขึ้นแถบแดงบนสุดของหน้าอาร์ต พร้อมชื่อ เบอร์ คนทำ และเวลา แถบอยู่จนกว่าอาร์ตจะกดรับทราบ · หน่อยเห็นในแท็บแจ้งเตือนด้วย |
| แจ้งเตือนเพิ่ม | ใบเบิกมีธงที่ยังไม่ตรวจ · รออนุมัติเกิน 2 วัน · เงินสำรองนุ้ยต่ำกว่า 3,000 · ยอดธนาคารไม่ตรง · บัญชี CEO เปลี่ยน |
| ตัวเลขบนแท็บ | รอจ่าย · รออนุมัติ · ตรวจสอบ · คำถามรอตอบ · ทะเบียนคนงานไม่ครบ |

ตัวเลขรวม: **unit 12/12 · database 33/33 (M1 17 + M2 16)** · typecheck และ build ผ่าน
เทสต์ database แต่ละไฟล์รันบนฐานข้อมูลใหม่เอี่ยม เพื่อไม่ให้ผลของไฟล์หนึ่งไปกระทบอีกไฟล์

ทดลองกดผ่านหน้าเว็บจริงด้วย (Chromium + PostgREST, จำลองที่เก็บรูป):
1. เป้อกรอกทะเบียนช่างอ้นจนครบ แล้วขอเบิกค่าแรง + วัสดุ พร้อมรูปงาน
2. นุ้ยถ่ายรูปผู้รับเงินแล้วกดจ่าย
3. กวางอนุมัติและโอน 12,065 พร้อมสลิป และกดไม่อนุมัติใบเบิกเงินเดือนหนึ่งใบ
4. กวางถามคำถาม เป้อตอบ แล้วตรวจผ่าน
5. กวางใส่ยอดธนาคารผิด แล้วแจ้งเตือนขึ้น
6. นุ้ยให้สิทธิ์ CEO กับหน่อย แถบแดงขึ้นที่หน้าอาร์ต อาร์ตกดรับทราบ

หน้ามือถือ 390px ไม่ล้นจอ และไม่มี error ในหน้าเว็บ

## สิ่งที่ต้องรู้

1. **ทะเบียนคนงานย้ายมาอยู่ M2** เพราะถ้ายังไม่มี จะเบิกค่าแรงไม่ได้เลย (ระบบไม่ยอมให้เลือกคนงานที่ข้อมูลยังไม่ครบ) ตอนนี้ช่างทั้ง 5 คนยังขาดเลขบัตรและรูปบัตร **ต้องให้เป้อ/นุ้ยกรอกให้ครบก่อนใช้จริง**
2. ธง "คนงานไม่ได้ลงเวลา" และ "ลงเวลาห่างหอ" ยังปิดไว้ (เปิดด้วยค่าตั้ง `attendance_required` ใน M3) ไม่อย่างนั้นทุกใบเบิกค่าแรงจะขึ้นธงหมด เพราะยังไม่มีระบบลงเวลา
3. แจ้งเตือนบัญชี CEO **แสดงในแอปเท่านั้น** ถ้าอยากให้เด้งเข้า LINE หรืออีเมลด้วย ต้องใช้ LINE Official Account (Messaging API) เพราะ LINE Notify ปิดบริการไปแล้ว ทำเพิ่มได้ภายหลังแยกเป็นงานย่อย
4. ตอนอาร์ตสร้างบัญชีตัวเองครั้งแรกผ่าน SQL ก็จะขึ้นแจ้งเตือน 1 รายการเช่นกัน ให้กดรับทราบครั้งเดียว
5. "โอนให้เจ้าของแล้ว" แสดงแยกไว้ และไม่นำไปลดยอด "เจ้าของค้างหอ" เพราะถือเป็นการถอนกำไร ไม่ใช่การคืนเงินที่ยืม (ตามสูตรใน SPEC §4.7) ถ้าคุณอาร์ตอยากให้หักด้วย บอกได้ครับ
