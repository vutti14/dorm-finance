# รายงาน M3 — ทีมช่าง: ลงเวลา · ส่งงาน · ขอเบิก

วันที่ 1 ต.ค. 69 · สร้างตาม SPEC §4.8 และ §9 M3

## สรุป

ช่างกับแม่บ้านทำเอกสารเองจากมือถือ: **ลงเวลาเข้า (เซลฟี่ + GPS) → ส่งงาน (รูปงาน 1–5 รูป)** แล้วระบบสร้างค่าแรงวันนั้นให้เองโดยไม่ต้องกรอกฟอร์ม
ช่างขอเบิกค่าวัสดุพร้อมรูปใบเสร็จได้ด้วย ส่วนเป้อเปิดแท็บ "ลงเวลางาน" เห็นงานของทุกคนพร้อมรูป แล้วกด **ยืนยันทั้งหมด** ครั้งเดียว
ระบบรวมเป็นใบเบิกและส่งต่อให้คนอนุมัติ/จ่ายตามยอด (กติกาเดียวกับ M2)
ถ้าสัญญาณหน้างานหลุด ระบบเก็บรายการไว้ในเครื่องแล้วส่งเองเมื่อมีเน็ต และ **ส่งซ้ำก็ไม่เกิดรายการซ้ำ**

## ทำอะไรไปแล้ว

| ส่วน | รายละเอียด |
|---|---|
| ช่างล็อกอินเอง | เบอร์โทร + PIN (ระบบเดียวกับทุกคน) · ครั้งแรกต้องกดยินยอม PDPA · มี 2 แท็บ: **ลงเวลางาน · ประวัติของฉัน** · เห็นแค่ข้อมูลของตัวเอง |
| ลงเวลาเข้า | เลือกโครงการ → พิมพ์งานวันนี้ → เซลฟี่กับหน้างาน (กล้องหน้า) → ส่งพิกัด GPS (ความแม่นยำสูง รอ 10 วิ) · ระบบคิดระยะห่างจากหอให้เอง (N/N503 → นารา, P → ปรายดาว) · ลงได้วันละครั้ง |
| ส่งงาน | รูปงาน 1–5 รูป + บอกว่าทำอะไรเสร็จ + ประเภทงาน/ห้อง → **ระบบสร้างค่าแรงวันนั้นให้เอง** (ตามค่าแรงในทะเบียน) |
| ขอเบิกค่าวัสดุ | ชื่อร้าน + จำนวนเงิน + โครงการ + รูปใบเสร็จ |
| ประวัติของฉัน | ค่าแรง/ค่าวัสดุ 60 วัน แสดงสถานะ **รอเป้อยืนยัน → รอจ่าย → จ่ายแล้ว** (พร้อมรูปหลักฐานจ่าย) หรือ ไม่อนุมัติ + เหตุผล · มีตารางลงเวลา 31 วัน |
| **โหมดหัวหน้าทีม** | เป้อ/นุ้ยตั้งใครเป็นหัวหน้าทีมได้ในทะเบียนคนงาน · หัวหน้าติ๊กลูกทีมที่มา → ถ่ายรูปหมู่ 1 รูป → ลงเวลา/ส่งงานแทนทั้งทีม · แต่ละคนได้แถวของตัวเอง (บันทึกว่า "หัวหน้าทีมลงให้") · ใครลงเวลาเองแล้วจะถูกข้ามพร้อมข้อความ |
| **สัญญาณอ่อน** | ลงเวลา / ส่งงาน / ขอเบิก เก็บไว้ในเครื่อง (IndexedDB) พร้อมรูปที่บีบแล้ว · ขึ้นแถบ "รอส่ง n รายการ" · ส่งเองเมื่อเน็ตกลับมา (และลองทุก 20 วิ) · ใช้เวลาจากเซิร์ฟเวอร์เป็นเวลาทางการ ส่วนเวลาในเครื่องเก็บไว้ดูประกอบ |
| ยืนยันงานวันนี้ (เป้อ) | รวมงานทุกคนของวันนั้น แยกตามโครงการ พร้อมรูปงาน/ใบเสร็จ และธงเรื่องพิกัด/ทะเบียนไม่ครบ · ไม่อนุมัติทีละรายการได้ (ต้องใส่เหตุผล) · **ยืนยันทั้งหมด** → ได้ใบเบิก 1 ใบต่อวัน ระบบเลือกคนอนุมัติ/จ่ายตามยอดให้ · ถ้ามี 2 คนกดพร้อมกัน สำเร็จแค่คนเดียว |
| ลงเวลาแทน | เป้อลงเวลาเข้าและส่งงานแทนคนงานที่ไม่มีมือถือได้ (บันทึกว่า "ผู้จัดการลงแทน") |
| แท็บขอเบิกของเป้อ | ติ๊กคนที่ลงเวลาแล้วแต่ยังไม่ส่งงานให้อัตโนมัติ พร้อมโครงการ |
| ธง / แจ้งเตือน | ไม่มีพิกัด · ห่างหอเกิน 300 ม. · ไม่ได้ส่งงาน · ส่งงานเกิน 12 ชม. หลังลงเวลา · ใบเบิกค่าแรงของคนที่ไม่ได้ลงเวลาวันนั้น (เปิดธงนี้แล้ว) · ค่าแรงรอเป้อยืนยันค้างจากวันก่อน · แท็บลงเวลางานของเป้อมีตัวเลขบอกจำนวนรอยืนยัน |

## ผลทดสอบ §10

| ข้อ | ผล | ทดสอบอย่างไร |
|---|---|---|
| 9 ลงเวลาห่างหอ 5 กม. | ✅ ผ่าน | บันทึกได้ ระยะ ~5,000 ม. ขึ้นธง "ห่างหอ" และขึ้นในแจ้งเตือน · ไม่มี GPS ก็บันทึกได้แต่ขึ้นธง "ไม่มีพิกัด" |
| 9a ช่าง 5 คน 5 เครื่องในนาทีเดียว | ✅ ผ่าน | ทั้ง 5 คนลงเวลาและส่งงานพร้อมกัน → ได้ 5 แถวลงเวลาและค่าแรง 5 รายการ · เป้อเห็นครบ 5 รายการ · กดยืนยันพร้อมกัน 2 คน สำเร็จแค่คนเดียว ได้ใบเบิกถูกเส้นทาง พร้อมรูปงานและใบเสร็จ |
| 9b หัวหน้าส่งทีม 4 คน มี 1 คนลงเองแล้ว | ✅ ผ่าน | สร้าง 3 แถว ข้าม 1 คนพร้อมข้อความ "ลงเวลาวันนี้เองแล้ว — ข้าม" · ตอนส่งงานก็ไม่เบิกค่าแรงคนนั้นซ้ำ |
| 9c มือถือออฟไลน์ตอนส่งงาน | ✅ ผ่าน | ฝั่งฐานข้อมูล: ส่งรายการเดิมซ้ำ (รวมถึงส่งพร้อมกัน 2 ครั้ง) ได้แค่ 1 แถว · ฝั่งเครื่อง: รายการอยู่ในคิวระหว่างออฟไลน์ แล้วส่งครั้งเดียวเมื่อกลับมาออนไลน์ ใช้ client_ref และ path รูปเดิมตอนส่งซ้ำ · ถ้าเซิร์ฟเวอร์ปฏิเสธ (เช่น ลงเวลาไปแล้ว) ระบบเอาออกจากคิวและบอกผู้ใช้ |

ตัวเลขรวม: **unit 16/16 (เพิ่มเทสต์คิวออฟไลน์ 4) · database 43/43 (M1 17 + M2 17 + M3 9)** · typecheck และ build ผ่าน

ทดลองกดผ่านหน้าเว็บจริงบนจอมือถือ 390px (Chromium + GPS จำลอง + ที่เก็บรูปจำลอง):
1. ช่างอ้นกดยินยอม ลงเวลาพร้อมเซลฟี่ แล้วส่งงาน
2. ช่างเอ **ปิดเน็ต** แล้วลงเวลา → ขึ้น "รอส่ง 1 รายการ" → เปิดเน็ต → ส่งเองครั้งเดียว (ระยะ 5,009 ม. ขึ้นธง)
3. ช่างเอส่งงานและขอเบิกวัสดุ 480
4. เป้อกดยืนยันทั้งหมด → ระบบไม่ยอม เพราะช่างเอเลขบัตรไม่ถูก → เป้อกดไม่อนุมัติรายการนั้น → ยืนยันใหม่ได้ใบเบิก R1
5. ประวัติของช่างแสดง "รอจ่าย" และ "ไม่อนุมัติ + เหตุผล" ถูกต้อง

## สิ่งที่ต้องรู้

1. **ต้องผูกบัญชีช่างกับทะเบียนคนงาน**: ตอนสร้างบัญชีช่างในแท็บผู้ใช้งาน ต้องเลือกคนในทะเบียน (ระบบบังคับอยู่แล้ว)
2. ใบเบิกจากการยืนยันงาน = 1 ใบต่อวัน รวมค่าแรง + วัสดุของวันนั้น และเลือกผู้อนุมัติ/ผู้จ่ายจากยอดรวม (ถ้าเกิน 3,000 กวางต้องอนุมัติก่อน)
3. GPS จับได้เฉพาะตอนกดปุ่ม ไม่ติดตามตลอด · ถ้ามือถือไม่ให้สิทธิ์ตำแหน่ง ระบบยังบันทึกได้ แต่จะขึ้นธง "ไม่มีพิกัด"
4. รูปลงเวลา/ส่งงานของช่างเก็บที่ `crew/<บัญชี>/` ใน Storage แบบ private · ช่างเห็นแค่รูปของตัวเอง
5. เวลาที่ใช้เป็นทางการคือเวลาที่เซิร์ฟเวอร์ได้รับ ถ้าส่งตอนออฟไลน์แล้วไปส่งได้ตอนเลิกงาน เวลาลงเวลาเข้าจะเป็นเวลาที่ส่งถึง (มีเวลาในเครื่องเก็บไว้ให้ดูประกอบ)
