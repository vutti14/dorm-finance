# รายงาน M4 — จดมิเตอร์ในแอป + AI อ่านเลขจากรูป

วันที่ 1 ต.ค. 69 · สร้างตาม SPEC §7 (จดมิเตอร์) และ §9 M4 และคำขอของคุณอาร์ต "ถ่ายรูปแล้วออกบิลค่าไฟได้เลย"

## สรุป

**ทำได้** — เป้อถ่ายรูปมิเตอร์ (ให้เห็นสติกเกอร์เลขห้อง) → **AI อ่านเลขให้ภายในไม่กี่วินาที** → ระบบใส่ "เลขครั้งก่อน" จากรอบที่แล้วให้เอง
→ แสดง `ค่าไฟ 1,100 → 1,180 = 80 หน่วย × 8 = 640 บาท` ทันที → เป้อกดบันทึก → **บิลห้องนั้นคำนวณใหม่ทันที** (เห็นยอดรวมบิล)

- AI เป็นตัวช่วย ไม่ใช่ตัวตัดสิน: คนต้องดูเลขเทียบรูปแล้วกดบันทึกเองทุกครั้ง (ตาม SPEC "human confirms every reading")
- ถ้า AI อ่านไม่ได้ / รูปเบลอ / ยังไม่เปิดใช้ AI → ขึ้นข้อความ แล้วพิมพ์เลขเองได้เลย (ทางเดิม)
- ไม่ต้องใช้รูปเดือนก่อน: ระบบมีเลขครั้งก่อนอยู่แล้วในฐานข้อมูล ใช้รูปเดือนนี้รูปเดียวพอ

## ทำอะไรไปแล้ว

| ส่วน | รายละเอียด |
|---|---|
| เริ่มรอบบิลใหม่ในแอป | กรอกชื่อรอบ / เดือนที่จด / วันออกบิล / วันครบกำหนด → ระบบสร้างบิลทุกห้องจากข้อมูลห้อง/ผู้เช่าปัจจุบัน และดึงเลขครั้งก่อน + หน่วยที่ใช้เดือนก่อนให้เอง · มีรอบที่ยังไม่วางบิลค้างอยู่จะเริ่มใหม่ไม่ได้ |
| แท็บจดมิเตอร์ | แยก นารา / ปรายดาว · นับ "จดแล้ว x / y ห้อง" และ "ห้องมีผู้เช่ายังไม่จด (วางบิลไม่ได้)" · ซ่อนห้องที่จดแล้ว (ติ๊กดูทั้งหมดได้) · ตัวเลขบนแท็บบอกจำนวนห้องที่ยังไม่จด |
| จดทีละห้อง | ถ่ายรูป (กล้องหลัง) → AI อ่าน → ใส่เลขให้ในช่อง → แสดงค่าไฟ/ค่าน้ำและธงผิดปกติก่อนบันทึก → "บันทึก → ห้องถัดไป" (ถ้าห้องนั้นมีมิเตอร์น้ำ จะพาไปจดน้ำต่อก่อน) |
| ธงทันที | ธงชุดเดียวกับ §4.6: ยังไม่จดไฟ · เลขไฟลดลง · มีผู้เช่าแต่ไม่ใช้ไฟ · ใช้ไฟเกิน 2 เท่าของเดือนก่อน · ห้องว่างแต่มีการใช้ไฟ/น้ำ |
| AI เตือนเพิ่ม | AI ไม่มั่นใจ · **สติกเกอร์ในรูปไม่ตรงกับห้องที่เลือก** (กันถ่ายผิดห้อง) · เลขน้อยกว่าครั้งก่อน · ใช้เกิน 2 เท่า |
| หลักฐาน | เก็บรูป (Storage แบบ private, `meters/<รอบ>/…`) · เลขที่ AI อ่าน (`ai_value`) แยกจากเลขที่คนยืนยัน · ใครจด เมื่อไร |
| นำเข้า Excel ยังใช้ได้ | ถ้านำเข้าแบบฟอร์มทับรอบที่จดในแอปไปแล้ว เลขจากมือถือ **ไม่หาย** (ช่องว่างใน Excel ใช้เลขจากมือถือ · ช่องที่พิมพ์ใน Excel ใช้เลขจาก Excel) |
| ล็อก | วางบิลแล้วแก้เลขมิเตอร์ไม่ได้ (ต้องให้กวางเพิ่มรายการปรับพร้อมเหตุผล ตามเดิม) · แก้ "เลขครั้งก่อน" จากหน้านี้ไม่ได้ (กันแก้ย้อนหลังเงียบ ๆ) — ใส่เองได้เฉพาะห้องที่ไม่มีข้อมูลเดิม |
| สิทธิ์ | จด/เริ่มรอบ: เป้อ · นุ้ย · CEO · กวาง/หน่อย/ช่าง ทำไม่ได้ |

## AI ทำงานอย่างไร

- Edge function `read-meter` ดึงรูปจาก Storage แล้วส่งให้ Claude (vision) อ่าน ตอบกลับเป็นโครงสร้างตายตัว: เลขที่อ่านได้ · ตัวเลขที่เห็น · ป้ายห้องที่เห็น · ความมั่นใจ · เหตุผลถ้าอ่านไม่ได้
- บอก AI ให้อ่านเฉพาะหลักเต็ม ไม่เอาช่องสีแดง/หลังจุด และถ้าเลขกำลังหมุนให้เอาค่าที่น้อยกว่า
- API key เก็บเป็น secret ของ Supabase function เท่านั้น ไม่อยู่ในหน้าเว็บหรือ repo (ดู [deploy.md](deploy.md) ข้อ 6)
- **ค่าใช้จ่ายโดยประมาณ**: รูปละราว 2,000 tokens ขาเข้า · เดือนละ ~75 ห้อง × (ไฟ + น้ำบางห้อง) ≈ 100–150 รูป → ประมาณหลักสิบบาทต่อเดือน (ตรวจราคาจริงที่หน้า pricing ของ Anthropic) · เปลี่ยนเป็นโมเดลที่ถูกกว่าได้ด้วย `METER_AI_MODEL`
