# รายงาน M5 — รายงานกำไร (NOI) + ส่งออก Excel

วันที่ 1 ต.ค. 69 · สร้างตาม SPEC §9 M5

## สรุป

แท็บ **ภาพรวม** (CEO · กวาง · หน่อย) มีรายงาน **กำไรจริงจากการดำเนินงาน (NOI) รายเดือน แยกอาคาร × ค่าห้อง / ไฟ / น้ำ**
คิดแบบเดียวกับแดชบอร์ด NOI เดิมของคุณอาร์ต — ม.ค.–ก.ย. 69 ดึงตัวเลขจากแดชบอร์ดเดิม (สมุดมือ) ตั้งแต่ ต.ค. 69 ระบบคำนวณเองจากเงินเข้า-ออกจริง
กดปุ่มเดียวได้ไฟล์ Excel 3 แผ่น: NOI · บัญชี (ทุกรายการเงินเข้า-ออก) · บิล (ทุกห้องทุกรอบ)

## วิธีคิด (เหมือนแดชบอร์ดเดิม · เกณฑ์เงินสด)

| บรรทัด | มาจาก |
|---|---|
| รายได้ | เงินค่าห้องที่ **รับจริง** ในเดือนนั้น (รวมยอดค้างที่ตามเก็บได้และค่าปรับ) |
| ค่าไฟ / ค่าน้ำที่เรียกเก็บ | ยอดในบิลของรอบที่ออกเดือนนั้น (ไม่นับห้องว่าง/ห้องพนักงาน) |
| **กำไรค่าไฟ** | ค่าไฟที่เรียกเก็บ − บิล กฟภ. (ทั้งที่เจ้าของจ่ายแทน และที่หอจ่ายเอง) |
| **กำไรค่าน้ำ** | ค่าน้ำที่เรียกเก็บ − บิลประปา |
| ค่าใช้จ่ายดำเนินงาน | ค่าแรง · วัสดุ · ส่วนกลาง · เงินเดือน — ของอาคารไหนลงอาคารนั้น · ของส่วนกลาง/เงินเดือนแบ่งตามจำนวนห้อง **นารา 32 : ปรายดาว 38** (แก้ได้ที่ตั้งค่า) |
| **กำไรจากค่าห้อง** | รายได้ − ค่าไฟ/น้ำที่เรียกเก็บ − ค่าใช้จ่ายดำเนินงาน |
| **NOI** | กำไรค่าห้อง + กำไรค่าไฟ + กำไรค่าน้ำ |
| แยกไว้ ไม่อยู่ใน NOI | งบลงทุน (เช่น ห้อง 503) · เงินประกันรับสุทธิ (หนี้สิน) · ค่าใช้จ่ายอสังหาฯ ของเจ้าของ · โอนระหว่างบัญชี · โอนให้/เติมจากเจ้าของ |

## สิ่งที่เพิ่มเพื่อให้คิดกำไรค่าน้ำ/ไฟได้

- ใบเบิก **ค่าใช้จ่ายส่วนกลาง** มีช่องเลือกประเภท: ค่าใช้จ่ายทั่วไป / **บิลค่าน้ำประปา** / **บิลค่าไฟ กฟภ.** (ต้องเลือกอาคาร) → ตอนจ่าย ระบบลงหมวด "บิลค่าน้ำประปา" / "บิลค่าไฟ กฟภ." ให้เอง
- ค่าไฟที่เจ้าของจ่ายแทน (ปุ่มเดิมของกวาง "เจ้าของจ่ายแทน") นับเป็นบิล กฟภ. ของอาคารนั้นอัตโนมัติ
- ตั้งค่า: เพิ่มช่อง "แบ่งค่าใช้จ่ายร่วม (จำนวนห้อง นารา : ปรายดาว)"

## สิ่งที่ต้องรู้

1. บิล กฟภ. / ประปา **ลงตามวันที่จ่าย** (เกณฑ์เงินสดเหมือนแดชบอร์ดเดิม) — ถ้าประปาเรียกเก็บ 2 เดือนรวมกัน กำไรค่าน้ำเดือนนั้นจะติดลบ (แบบเดียวกับ ก.ค. ในแดชบอร์ดเดิม) ให้ดูยอดรวมหลายเดือนเป็นหลัก
2. ถ้าใบเบิกค่าน้ำประปาไม่ได้เลือกประเภท "บิลค่าน้ำประปา" ระบบจะนับเป็นค่าใช้จ่ายทั่วไป กำไรค่าน้ำจะสูงเกินจริง (NOI รวมยังถูก)
3. ประวัติ ม.ค.–ก.ย. โหลดครั้งเดียวด้วย `scripts/import-opening.ts` จาก `reference/NOI-dashboard.html` (ไม่อยู่ใน git)
4. PDF บิล (SPEC เขียนว่าไม่บังคับ) ยังไม่ทำ — ตอนนี้ใช้ข้อความบิลส่ง LINE เหมือนเดิม

## คำถามถึงคุณอาร์ต

1. **รายได้อื่น** (ซักผ้า ตู้น้ำ keycard ดอกเบี้ย) — แดชบอร์ดเดิมมีบรรทัดนี้ แต่ระบบยังไม่มีปุ่มบันทึกรายได้อื่น ต้องการให้เพิ่มไหม (ตอนนี้ไม่อยู่ใน NOI)
2. ต้องการ **PDF บิล** สำหรับส่งผู้เช่าไหม หรือข้อความ LINE พอแล้ว
