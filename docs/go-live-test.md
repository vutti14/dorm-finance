## ปัญหาที่เจอและแก้แล้ว (เจอเฉพาะบน Supabase จริง เทสต์เดิมจับไม่ได้)

1. **นำเข้า Excel พัง** — Supabase ไม่ยอมให้ UPDATE ที่ไม่มี WHERE ผ่าน API (pg_safeupdate) · แก้แล้ว + เพิ่มเทสต์ตรวจทุกฟังก์ชันกันพลาดซ้ำ
2. **หน้าจอคนอื่นไม่อัปเดตตอนนำเข้า/วางบิลทั้งรอบ** — ระบบส่งข้อความทีละแถว (หลายร้อย) จนชนเพดานของ Supabase แล้วโดนทิ้ง · แก้เป็นส่ง "มีการเปลี่ยนแปลง" 1 ครั้งต่อตารางต่อรายการ + ทุกหน้าใช้ช่องเดียว → อัปเดตใน < 1.5 วิ
3. **ตั้งค่า auth ใน config.toml ปิดการล็อกอินด้วยอีเมลไปด้วย** (เฉพาะตอนรันในเครื่อง) · แก้แล้ว — บน supabase.com ตั้งจากหน้า dashboard ตามคู่มือ
4. **รูปมิเตอร์น้ำที่บันทึกไว้ไม่แสดง** · แก้แล้ว

## ยังต้องทดลองหลังขึ้นระบบจริง

- AI อ่านรูปมิเตอร์ (ต้องตั้ง `ANTHROPIC_API_KEY`) — ปุ่ม deploy จะทดลองด้วยรูปตัวอย่าง (ต้องอ่านได้ 1180) ให้อัตโนมัติ
- แชร์รูปบิลเข้า LINE บนมือถือจริง · กล้อง/GPS บนมือถือจริง
